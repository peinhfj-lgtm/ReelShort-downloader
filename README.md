# ReelShort Downloader

A Python-based downloader for ReelShort. Given a `book_id`, it fetches all episodes of a series and saves them locally.

## Features

- Fetch all episodes of a series by `book_id`
- Download episode videos to local storage
- Simple and easy-to-use interface
- Configurable output directory
